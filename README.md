NOW with that aside. Nachts FOV is a Gorilla Tag mod that lets you widen your field of view. It was made because I wanted to try it myself, and I knew other people were looking for something like it, but all of them were broken and noone would even try making it.

It uses Harmony to find the headset’s XR projection, which is what controls how wide your view is, and changes it to whatever FOV you pick.

Press F to open the menu. There is a slider that goes from 40 to 170 . It defaults to 140 (do NOT rec using that for the first time, as it can be very odd), and there’s a reset button if you go too far.

Requires BepInEx and Harmony.
